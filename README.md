# Star Catcher

A tiny browser arcade game: catch as many stars as you can in 30 seconds.

## Play

Open `index.html` in a modern web browser, press **Start playing**, and click or tap the stars before they disappear. Your personal best is saved in your browser.

## Files

- `index.html` — game page and interface
- `style.css` — responsive styling and animations
- `script.js` — gameplay, scoring, and timer
